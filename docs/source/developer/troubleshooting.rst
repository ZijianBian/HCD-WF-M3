Troubleshooting
===============

Start with the environment checks in :doc:`setup`, then confirm the
selected actors and topology against :doc:`../user/execution_modes`.
Build and runtime requirements are in :doc:`actor_installation`.

For a Hybrid clock error, compare incoming message times with the
:ref:`hybrid-clock-contract`. For a rejected Pure concurrency setting,
check the Cyrano requirements in :ref:`pure-m3-scheduling`.
