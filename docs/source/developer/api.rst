API and Module Reference
========================

This page lists the modules most relevant to current M3 development. It avoids
autogenerated API dumps so the manual stays readable.

Workflow Drivers
----------------

.. list-table::
   :header-rows: 1

   * - Module
     - Main role
   * - ``workflow.workflow_driver``
     - Legacy driver and Hybrid M3 macro.
   * - ``workflow.wf_wrapper``
     - Compatibility wrapper importing ``workflow_driver``.
   * - ``hcdworkflow.hcd_workflow_m3``
     - Hybrid M3 micro model.
   * - ``hcdworkflow.workflow_driver_m3_pure``
     - Pure M3 actor driver.

Core Workflow
-------------

.. list-table::
   :header-rows: 1

   * - Module
     - Main role
   * - ``hcdworkflow.hcd_workflow``
     - Classic workflow orchestration.
   * - ``hcdworkflow.workflow_executor``
     - Actor dependency and execution logic.
   * - ``hcdworkflow.workflow_data``
     - Parsed workflow configuration and process state.
   * - ``hcdworkflow.workflow_config_reader``
     - ``input_workflow.xml`` parser.
   * - ``hcdworkflow.workflow_dbhelper``
     - IMAS database helper.

IDS Utilities
-------------

.. list-table::
   :header-rows: 1

   * - Module
     - Main role
   * - ``workflow.ids_prep``
     - DD fix-ups, waveform helpers, direct-driver IDS preparation, and
       toroidal mode utilities.

Where to Start
--------------

For Pure M3 work, start with:

* ``hcdworkflow/workflow_driver_m3_pure.py``
* ``workflow/ids_prep.py``
* The yMMSL file for the case under test.
