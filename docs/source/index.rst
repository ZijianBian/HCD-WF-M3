HCD Workflow Documentation
===========================

Welcome to the HCD (Heating and Current Drive) Workflow documentation for ITER plasma simulations.

The HCD Workflow is a Python-based workflow management system designed to orchestrate various heating and current drive simulation codes for ITER tokamak plasma physics analysis.
